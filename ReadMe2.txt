nanoRQc
Simpler version of nanorq for the convenience.
It only supports core feature (encoder and decoder) of RaptorQ.

MIT License

Copyright (c) 2026 Yutaka Sawada

 Yutaka Sawada modified nanorq.
I changed some nanorq's APIs for easy usage.
While this supports single block only, larger symbol size is possible.

If you want full support of RFC 6330, use original nanorq above.
Or I made nanorq for Visual C, too.
https://github.com/Yutaka-Sawada/nanorq_vc

I put a sample code (main.c) to test usage.
